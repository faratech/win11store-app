WindowsForum for Windows

This directory contains the WindowsForum Progressive Web App release packages.

Install the sideload package

Windows 10 version 19041 or later and Microsoft Edge Stable are required. Keep install.ps1, WindowsForum.sideload.msix, and utils/pwainstaller.exe together, then run Windows PowerShell in this directory:

Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1

Use .\install.ps1 -NoLaunch when testing installation without opening the app. The script installs for the current user and launches the exact registered WindowsForum package.

Package choices

  • WindowsForum.sideload.msix is the package used by the local installer.
  • WindowsForum.msixbundle is the modern bundle for Store-style distribution.
  • WindowsForum.classic.appxbundle is the legacy classic bundle.

The Store submission uses the two bundle files; the PowerShell helper is not embedded in, or executed by, Store packages.

Security and support

Obtain packages from a trusted release and verify the published checksums. Direct sideload releases must also provide trusted signatures; Store packages are signed during Store publishing. Do not run the helper from an untrusted download. Visit WindowsForum.com for the current site and support.
